# LiteDoc Browser 隐私政策

更新日期：2026-05-27

生效日期：2026-05-27

LiteDoc Browser 是一款用于查看本地 HTML 和 Markdown 文件的轻量文档浏览工具。我们重视你的隐私和数据安全，本政策说明应用如何处理信息。

## 信息收集

当前版本的 LiteDoc Browser 不收集、上传或共享你的个人信息。

应用不会要求注册或登录，不会收集姓名、手机号、邮箱、账号、通讯录、定位、设备标识等个人信息。

## 文件访问

当你在应用内选择文件，或通过系统文件管理器的“打开方式”使用 LiteDoc Browser 打开文件时，应用会读取你主动选择的本地 HTML 或 Markdown 文件内容。

读取文件的目的仅限于在你的设备本地渲染和显示文档内容。应用不会将文件内容上传到服务器，也不会与第三方共享文件内容。

## 网络与第三方服务

当前版本不提供云同步功能，不内置广告 SDK，不内置统计分析 SDK，也不会主动向服务器上传使用数据。

如果你打开的 HTML 文件自身包含远程图片、脚本或链接，这些内容可能由系统 Web 渲染能力按网页规则加载。请仅打开你信任来源的 HTML 文件。

## 权限使用

应用仅在你主动选择或打开文件时，通过系统文件访问能力读取对应文件。应用不会扫描你的文件系统，也不会后台读取其他文件。

## 儿童隐私

LiteDoc Browser 面向一般用户提供本地文档查看功能，不主动收集任何儿童个人信息。

## 政策更新

如果后续版本增加同步、AI 接口、账号或网络服务，我们会在功能上线前更新本隐私政策，并说明新增的数据处理方式。
